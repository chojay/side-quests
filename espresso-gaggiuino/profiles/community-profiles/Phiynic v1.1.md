# Phiynic v1.1

A guided base profile with a saturation peak, pressurized extraction, and taper, meant to be tuned per bean.

This profile is community-authored and distributed from the official
[Gaggiuino community profiles branch](https://github.com/Zer0-bit/gaggiuino/tree/community/profiles).
The JSON is not redistributed here; download `Phiynic v1.1.json` from that branch and
import it through the Gaggiuino web UI (see the
[import guide](../Gaggiuino-Custom-Profiles-Import-Guide.md)). Authorship and
parameter details belong to the original contributors; consult the branch and
its linked discussion for the definitive description.
