# Research Methodologies Reference

## Domain-Specific Research Approaches

### Academic Research
- **Systematic Review Protocol**: PRISMA guidelines, inclusion/exclusion criteria
- **Meta-Analysis Framework**: Effect size calculations, heterogeneity testing
- **Evidence Hierarchy**:
  1. Systematic reviews and meta-analyses
  2. Randomized controlled trials (RCTs)
  3. Cohort studies
  4. Case-control studies
  5. Case reports and expert opinion

### Product Research
- **Feature Analysis Matrix**: Specifications × User needs × Price points
- **Review Mining Protocol**: Sentiment analysis, common complaint patterns
- **Cross-Market Comparison**: Regional availability, pricing variations
- **Total Cost of Ownership**: Initial cost + maintenance + accessories

### Medical/Health Research
- **Clinical Guidelines Search**: Professional societies, government agencies
- **Patient Population Analysis**: Demographics, comorbidities, contraindications
- **Safety Profile Assessment**: Adverse events, drug interactions
- **Efficacy Metrics**: NNT (Number Needed to Treat), absolute risk reduction

### Technical Documentation
- **API Documentation Review**: Endpoints, authentication, rate limits
- **Implementation Complexity**: Dependencies, learning curve, maintenance burden
- **Performance Benchmarks**: Speed, scalability, resource usage
- **Community Support**: GitHub stars, Stack Overflow activity, documentation quality

## Source Credibility Framework

### Credibility Score Calculation
```
Final Score = Base Score × Recency Factor × Corroboration Factor
```

### Base Scores by Source Type
| Source Type | Base Score | Verification Required |
|------------|------------|----------------------|
| Peer-reviewed journal | 0.95 | Impact factor check |
| Government database | 0.90 | Official domain verification |
| Industry expert (verified) | 0.85 | Credential verification |
| Professional review site | 0.80 | Editorial process check |
| Community consensus (n>100) | 0.75 | Sample size verification |
| Individual expert opinion | 0.70 | Expertise verification |
| User forums (n>20) | 0.60 | Community reputation |
| Anecdotal evidence | 0.50 | Context evaluation |
| Unverified claim | 0.30 | Requires corroboration |

### Recency Factors
- Current year: 1.0
- 1-2 years old: 0.95
- 3-5 years old: 0.85
- 6-10 years old: 0.70
- >10 years old: 0.50 (unless seminal work)

### Corroboration Multipliers
- 5+ independent sources agree: 1.2
- 3-4 sources agree: 1.1
- 2 sources agree: 1.0
- Single source only: 0.8
- Contradicted by other sources: 0.5

## Adversarial Analysis Framework

### Bias Detection Checklist
- [ ] Selection bias: Are we only seeing successful cases?
- [ ] Confirmation bias: Are we ignoring contradictory evidence?
- [ ] Recency bias: Are we overweighting recent information?
- [ ] Authority bias: Are we trusting sources without verification?
- [ ] Geographic bias: Are we missing regional perspectives?
- [ ] Survivorship bias: Are failed cases being reported?

### Red Team Questions
1. What would a skeptic argue against these findings?
2. What evidence would disprove the conclusions?
3. What alternative explanations exist?
4. What conflicts of interest might exist?
5. What's missing from the analysis?
6. How would this fail in edge cases?

### Uncertainty Quantification
- **High Certainty**: Multiple authoritative sources, large samples, recent data, minimal contradictions
- **Medium Certainty**: Some authoritative sources, moderate samples, mostly consistent
- **Low Certainty**: Few sources, small samples, contradictions present
- **Speculative**: Limited evidence, requires assumptions, future-oriented

## Research Quality Metrics

### Minimum Viable Research Criteria
- At least 5 diverse sources
- At least 2 geographic regions represented
- Mix of expert and user perspectives
- Sources from within last 3 years
- Contradictions addressed explicitly

### Quality Score Calculation
```
Quality Score = (Source Diversity × 0.3) + (Geographic Coverage × 0.2) +
                (Temporal Relevance × 0.2) + (Authority Mix × 0.15) +
                (Contradiction Resolution × 0.15)
```

### Research Completeness Checklist
- [ ] Primary sources consulted
- [ ] Expert opinions gathered
- [ ] User experiences analyzed
- [ ] Cross-cultural perspectives included
- [ ] Contradictions resolved or documented
- [ ] Confidence levels assigned
- [ ] Future monitoring plan created
- [ ] Knowledge gaps identified
